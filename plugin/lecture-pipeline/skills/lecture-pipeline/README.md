# lecture-pipeline — 강의 영상 자동 정돈 파이프라인

유튜브 강의 URL 하나로 **편집본 영상 + 목차·요약·검색용 데이터**를 만들어 주는 Claude Code 스킬입니다.
만들어진 산출물을 뷰어 웹에 업로드하면 목차 점프·본문 검색·편집 검토가 되는 페이지가 됩니다.

- **자르는 것:** 잘못 말하고 고쳐 말한 앞부분(실언 정정), 같은 내용을 다시 말해 앞 시도가 흡수된 구간(의미 중복)
- **자르지 않는 것:** 필러(어·음·그), 더듬, 반복 단어, 멈춤, 잡음, 의도적 요약("다시 한번 말씀드리면")
- 원본은 그대로 두고 편집본을 따로 만듭니다. 모든 컷은 목록으로 남아 웹의 "편집 검토" 화면에서 원본과 대조할 수 있습니다.

## 준비물

파이썬 서드파티 패키지는 **하나도 필요 없습니다**(표준 라이브러리만 씁니다). 대신 아래 네 가지가 있어야 합니다.

| 필요한 것 | 용도 |
|---|---|
| Python 3.12+ | 파이프라인 스크립트 |
| ffmpeg / ffprobe | 영상 자르기·이어붙이기·썸네일 |
| yt-dlp | 유튜브 원본·자동자막 받기 |
| node 또는 deno | yt-dlp 가 유튜브 차단(403)을 피하는 데 필요 |

**무엇이 없는지는 직접 확인할 필요 없습니다.** Claude Code 에서 스킬을 실행하면 첫 단계가 환경 점검이고,
빠진 게 있으면 그 OS 에 맞는 설치 명령을 알려준 뒤 승인을 받아 대신 실행해 줍니다.

직접 점검하려면:

```bash
python3 <스킬폴더>/scripts/lp.py doctor
```

### OS별 메모

- **리눅스(우분투/데비안)** — `sudo apt install -y ffmpeg nodejs` + `uv tool install yt-dlp`(또는 `pipx install yt-dlp`)
- **macOS** — `brew install ffmpeg yt-dlp node`
- **윈도우** — **WSL2 를 권장합니다.** `wsl --install` 로 우분투를 깔면 위 리눅스 절차가 그대로 통하고, 이 파이프라인이 실제로 검증된 환경과 같아집니다.
  네이티브 윈도우에서도 동작하도록 만들었지만(`winget install Python.3.12 Gyan.FFmpeg yt-dlp.yt-dlp OpenJS.NodeJS`) 검증되지 않았고, 설치 후 PATH 반영을 위해 터미널을 새로 열어야 합니다.

## 사용법

Claude Code 에서 아무 **빈 폴더**를 열고:

```
/lecture-pipeline https://youtu.be/영상ID
```

산출물은 그 폴더 아래 `workspace/` 에 쌓입니다. 코드는 스킬 폴더 안에만 있고 작업 폴더를 더럽히지 않습니다.

```
workspace/
  raw/<영상ID>/        원본 mp4 · 자동자막 · 메타데이터 (다시 돌리면 재사용)
  build/<영상ID>/      중간 산출물(전사·청크·컷 목록·목차)
  out/<영상ID>/        ★ 업로드할 산출물
    original.mp4       원본        (편집 검토 화면 대조용)
    edited.mp4         편집본      (플레이어 본체)
    lecture.json       전사·컷·목차·노트
    thumbs/            챕터 썸네일 (zip 으로 묶어 올림 — 선택)
```

마지막에 뷰어 웹의 **업로드 화면**에서 위 3개(+썸네일 zip)를 올리면 자동으로 적재·색인되어 페이지에 반영됩니다.

**이 마지막 단계는 기본으로 자동입니다** — 뷰어 주소가 스킬에 내장돼 있어 설치 후 따로 설정할 것이 없습니다.
다른 뷰어에 올리려면 환경변수로 덮으면 됩니다.

```bash
export VCU_API=https://다른.뷰어/경로/api
export VCU_API_TOKEN=...      # 토큰을 요구하는 뷰어라면
```

올리고 싶지 않을 땐 `/lecture-pipeline <url> --no-upload` 로 건너뛸 수 있습니다.
업로드가 끝나면 적재·임베딩이 완료될 때까지 기다렸다가 강의 id 를 알려 줍니다(1.7GB · 2,250문장 기준 실측 1분 37초).
같은 영상을 다시 돌려도 앞 결과를 덮어쓰지 않고 목록에 새로 쌓입니다.

## 시간과 비용 (3시간짜리 강의 1편 기준, 실측)

| 단계 | 소요 |
|---|---|
| 원본·자막 받기 | 1~3분(회선에 따라) |
| 전처리·청크 | 수 초 |
| 컷 편집 판단(LLM 병렬) | 약 10분 |
| 목차·요약 구조화(LLM) | 약 8분 |
| 렌더 | **약 13~40분** (아래 실측 참고) |
| 웹 적재(업로드 후) | 2~3분 |

- 컷 편집 판단에 **Opus 서브에이전트를 많이 씁니다 — 3시간 강의 한 편에 대략 150만 토큰**. Claude 구독 사용량을 꽤 소모합니다.
- **렌더 실측**(1080p 화면 녹화 3분 구간, 3시간 27분으로 환산): libx264 veryfast 32스레드 약 12분 · **4스레드 약 13분** · NVENC(GPU) 약 14분.
  강의 영상은 움직임이 적어 CPU 인코딩이 잘 먹습니다 — **GPU 가 없어도 느리지 않습니다**(랩톱 코어가 서버보다 느린 걸 감안하면 20~40분).
  그래서 기본값(`auto`)은 코어가 8개 이상이면 libx264, 그 미만일 때만 GPU 를 씁니다. 필요하면 `--encoder` 로 직접 고르세요.
- 노트북이라면 전원을 꽂고 돌리세요(수십 분간 CPU 를 씁니다).

## 자주 막히는 곳

- **yt-dlp 가 403** — JS 런타임(node/deno)이 없거나 yt-dlp 가 오래됐을 때. `yt-dlp -U`(또는 `uv tool upgrade yt-dlp`) 후 재시도.
- **비공개(일부 공개) 영상** — 링크를 아는 사람이면 받아집니다. 완전 비공개 영상은 계정 인증이 필요해 지원하지 않습니다.
- **자동자막이 없는 영상** — 이 파이프라인은 유튜브 한국어 자동자막을 입력으로 씁니다. 자막이 아직 생성되지 않았으면 잠시 후 다시 시도하세요.
- **렌더가 너무 느림** — `--encoder h264_nvenc`(GPU) 로 바꿔 보거나, 원격 GPU 호스트가 있으면 `--ssh-host user@host` 를 붙이세요. 다만 실측상 대부분의 기기에서 CPU(libx264)가 이미 충분히 빠릅니다.

## 구조

```
scripts/
  lp.py                  단일 진입점 (doctor·fetch·preprocess·chunk·merge·render·assemble)
  lecture_pipeline/      기계 단계 구현 (표준 라이브러리만)
  schema/                lecture.json 스키마 — 웹 업로드 검증과 같은 파일을 쓴다
tests/                   pytest 35개 (pytest 만 있으면 실행 가능)
SKILL.md                 Claude 가 읽는 절차서 + 판단 단계 브리프
```

기계적으로 결정되는 것(타임스탬프 재매핑·컷 구간 계산·JSON 조립)은 전부 스크립트가, 판단이 필요한 것(무엇을 자를지·어떻게 나눌지)만 LLM 이 합니다. 그 경계가 이 파이프라인의 설계 핵심입니다.
